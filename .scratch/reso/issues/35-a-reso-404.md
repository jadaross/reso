# 35 — A Reso 404

**What's wrong:** A mistyped tab or a wrong Group Link shows the framework's white "404 / This page
could not be found." with no way back. It is the only screen that does not look like Reso.

**What to build:** A dark not-found page in the app's own type: "Nothing here." with "Back to
dinner →" when a Group Link cookie is present, and the same one-line explanation the root page
gives when it is not. It never reveals whether a secret was wrong.

**Blocked by:** nothing

**Status:** done

- [x] A wrong path under a valid Group Link shows the Reso not-found page with a link back to Dinner
- [x] A wrong secret shows the same page with the root page's one-line explanation and no link, so a wrong secret and a wrong path are indistinguishable
- [x] The page uses the field background and the app's fonts; no white flash
- [x] The tab names and their URLs agree, or the old URLs (restaurants, history) redirect to the tab names
